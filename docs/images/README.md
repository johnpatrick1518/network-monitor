# Screenshot placeholders

The SVG files in this folder are explicitly labeled placeholders, not generated screenshots or claims about a deployed service.

Before publishing:

1. Run `python -m app.demo` using the virtual environment.
2. Sign in using the temporary credentials printed in the terminal.
3. Capture the dashboard at desktop width with its **DEMO MODE** banner visible.
4. Open Office Printer or Home Server and capture the detail view with history.
5. Save as `dashboard.png` and `device-detail.png` here, then update README image paths.
6. Check for private data, browser profile details, saved-password popups, tokens, or terminal credentials before committing.

Only synthetic devices/SSID should appear. Do not capture real monitoring mode or `.env`.
